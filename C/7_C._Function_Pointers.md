# DAY 07 — 함수 포인터

## 1. 함수 이름과 함수 포인터

```c
int func(int a, int b) {
    return a + b;
}

int main(void) {
    printf("%d\n", (******func)(10, 20));
    return 0;
}
```

- 함수 이름은 대부분의 식에서 함수의 주소를 나타내는 함수 포인터로 변환된다.
- `func(10, 20)`과 `(*func)(10, 20)`은 동일하게 동작한다.
- 함수 포인터를 역참조한 결과는 다시 함수를 나타내므로, `*`를 여러 번 붙여도 호출할 수 있다.

## 2. 함수 포인터의 필요성

- 공통 동작은 유지하고, 달라지는 부분을 함수로 만들어 전달한다.
- 호출할 함수를 외부에서 지정할 수 있어 코드 중복을 줄일 수 있다.

### 예시: qsort()

- `qsort()`는 정렬 기준을 비교 함수의 포인터로 전달받는다.
- 비교 함수의 포인터형은 `int (*)(const void *, const void *)`이며, 작성한 함수의 이름을 인자로 전달한다.
- 오름차순·내림차순 등 정렬 기준을 사용자가 정할 수 있다.

## 3. 함수 포인터 변수 및 함수 포인터 배열

함수의 주소를 변수 하나에 저장하거나, 배열에 모아 저장할 수 있다.

```c
int sum(int x, int y);
int sub(int x, int y);
int mul(int x, int y);
int divi(int x, int y);
int mod(int x, int y);

int (*my_func)(int, int) = sum;
int (*func[5])(int, int) = {sum, sub, mul, divi, mod};
```

- **함수 포인터 변수**: 반환형과 매개변수 목록은 그대로 두고, 함수 이름 부분을 `(*변수명)`으로 바꾼다.
- **함수 포인터 배열**: `(*변수명[n])`처럼 괄호 안의 변수명 뒤에 `[n]`을 붙인다.

## 4. 함수 포인터 배열로 계산 결과 저장하기

아래 예제는 각각 실행한다.

### 직접 작성한 배열 버전

```c
#include "day7_lib.h"

int main(void) {
    int (*my_func)(int, int) = sum;
    int (*fp[])(int, int) = {sum, sub, mul, divi, mod};
    int a = 25, b = 6;
    int totalAry[SIZE(fp)] = {0};
    int totalSum = 0;

    for (int i = 0; i < SIZE(fp); i++) {
        totalAry[i] = fp[i](a, b);
        printf("totalAry[%d]: %d\t", i, totalAry[i]);
        totalSum += totalAry[i];
    }
    printf("\ntotalSum: %d\n", totalSum);
    return 0;
}
```

### 다른 분의 동적 메모리 버전

함수 포인터 배열의 원소 개수만큼 **`int` 결과를 저장할 공간**을 할당한다.

```c
#include "day7_lib.h"

int main(void) {
    int (*func[5])(int, int) = {sum, sub, mul, divi, mod};
    int a = 25, b = 6;
    int c = sizeof(func) / sizeof(*func);
    int *storage = (int *)malloc(sizeof(int) * c);
    int total = 0;

    for (int i = 0; i < c; i++) {
        total += storage[i] = func[i](a, b);
    }
    for (int i = 0; i < c; i++) {
        printf("%dth result: %d\n", i + 1, storage[i]);
    }
    printf("total: %d", total);
    free(storage);

    return 0;
}
```

### 교수님의 구조체 버전

함수 포인터·이름·결과를 하나의 구조체에 묶어 관리한다.

```c
#include "day7_lib.h"

typedef struct _my_t {
    int (*fp)(int, int);
    char *name;
    int res;
} my_t;

int main(void) {
    my_t funcs[] = {
        {sum, "sum"},
        {sub, "sub"},
        {mul, "mul"},
        {divi, "divi"},
        {mod, "mod"}
    };

    int a = 25, b = 6;
    int totalSum = 0;

    for (int i = 0; i < SIZE(funcs); i++) {
        funcs[i].res = funcs[i].fp(a, b);
        totalSum += funcs[i].res;
        printf("%s(%d,%d) = %d\n", funcs[i].name, a, b, funcs[i].res);
    }

    return 0;
}
```

## 5. `qsort` 비교 함수 실습

[실습 코드](./src/7_C_Function_Pointers.c)

```c
qsort(배열, 원소_개수, 원소_하나의_크기, 비교_함수);
```

비교 함수는 **비교할 두 원소의 주소**를 `const void *`로 받는다. 실제 자료형에 맞게 해석한 뒤 비교한다.

| 반환값 | 의미 |
| --- | --- |
| 음수 | 첫 번째 원소가 앞에 옴 |
| 0 | 두 원소의 정렬 순위가 같음 |
| 양수 | 첫 번째 원소가 뒤에 옴 |

### 실수 배열 정렬

```c
int compDouble(const void *a, const void *b) {
    if (*(const double *)a == *(const double *)b) return 0;
    return *(const double *)a > *(const double *)b ? 1 : -1;
}

// dary가 선언된 함수 안에서 사용
qsort(dary, SIZE(dary), sizeof(dary[0]), compDouble);
```

원소 하나가 `double`이므로, 주소를 `const double *`로 변환한 뒤 값을 읽는다.

### 문자열 포인터 배열 정렬

```c
int compStr(const void *a, const void *b) {
    return strcmp(*(char *const *)a, *(char *const *)b);
}

// 함수 안에서 사용
char *sary[] = {"kiwi", "banana", "melon", "apple", "orange"};
qsort(sary, SIZE(sary), sizeof(sary[0]), compStr);
```

원소 하나가 `char *`이므로, 비교 함수에는 **문자열 주소가 저장된 칸의 주소**가 들어온다. 이를 한 번 역참조해 문자열 주소를 꺼내 `strcmp`에 전달한다.

```text
정렬 결과: apple banana kiwi melon orange
```

### 2차원 배열을 두 번째 열 기준으로 정렬

```c
void print_2Darr(int (*arr)[3], int r, int c) {
    for (int i = 0; i < r; i++) {
        for (int j = 0; j < c; j++) {
            printf("%d ", arr[i][j]);
        }
        printf("\n");
    }
    printf("\n");
}

int comp2D(const void *a, const void *b) {
    const int *arr = *(const int (*)[3])a;
    const int *arrb = *(const int (*)[3])b;
    return arr[1] - arrb[1]; // 이 예제의 작은 정숫값을 비교
}

// 함수 안에서 사용
int arr[][3] = {{1, 3, 5}, {3, 1, 2}, {2, 4, 1}};
print_2Darr(arr, SIZE(arr), SIZE(arr[0]));
qsort(arr, SIZE(arr), sizeof(arr[0]), comp2D);
print_2Darr(arr, SIZE(arr), SIZE(arr[0]));
```

**정렬 원소 하나가 행 전체**이다. `SIZE(arr)`는 행 개수, `sizeof(arr[0])`은 한 행의 크기이다. 두 번째 열을 비교하되, 정렬할 때는 행 전체가 이동한다.

`*(const int (*)[3])a`는 행 배열을 꺼낸 뒤 첫 정수의 주소로 변환되는 식이다. 행 안의 값을 읽는 목적이라면 **`const int *arr = a;`로 바로 받아도 된다.**

```text
정렬 전       정렬 후
1 3 5         3 1 2
3 1 2         1 3 5
2 4 1         2 4 1
```

### 구조체 배열을 수학 점수 기준으로 정렬

```c
typedef struct _score_t {
    int kor;
    int eng;
    int mat;
} score_t;

void print_score(score_t *arr, int n) {
    for (int i = 0; i < n; i++) {
        printf("%d %d %d\n", arr[i].kor, arr[i].eng, arr[i].mat);
    }
    printf("\n");
}

int compScore(const void *a, const void *b) {
    const score_t *s = a;
    const score_t *c = b;
    return s->mat - c->mat;
}

// 함수 안에서 사용
score_t stu[5] = {
    {80, 90, 85},
    {100, 80, 70},
    {90, 95, 100},
    {88, 77, 50},
    {60, 30, 20}
};

qsort(stu, SIZE(stu), sizeof(stu[0]), compScore);
print_score(stu, SIZE(stu));
```

- `a`, `b`는 비교할 학생 구조체의 주소이다. 읽기만 하므로 `const score_t *`로 받는다.
- `s->mat`는 `(*s).mat`와 같으며, 수학 점수를 비교해 오름차순으로 정렬한다.
- **수학 점수만 따로 옮기는 것이 아니라 학생 구조체 전체를 이동**한다. 구조체 하나의 초기값은 `{국어, 영어, 수학}`처럼 중괄호로 묶는다.

```text
국어 영어 수학
60   30   20
88   77   50
100  80   70
80   90   85
90   95   100
```
