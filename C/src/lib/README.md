# 공용 C 라이브러리

- 함수 선언은 `.h`, 구현은 `.c` 파일로 이 폴더에 추가한다.
- 실습 파일에서는 `#include "day3_lib.h"`처럼 필요한 헤더를 포함한다.
- `main`은 이 폴더 밖의 실습 파일에 작성한다.
- 실습 파일에서 **Run Code (`Ctrl+Alt+N`)**를 누르면 현재 파일과 이 폴더의 모든 `.c` 파일을 함께 빌드하고 실행한다. 하위 폴더의 `.c`도 포함한다.
- 새 라이브러리 파일은 별도 등록 없이 다음 빌드부터 포함된다. 하위 폴더의 헤더는 `#include "폴더명/헤더명.h"`로 사용한다.
- 모든 구현을 함께 연결하므로, 파일 간에 외부로 공개하는 함수나 전역 변수의 이름이 중복되지 않도록 한다.
