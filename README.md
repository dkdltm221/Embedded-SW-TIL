# TheSSEN_TIL

**LIG D&A The SSEN 임베디드 SW 5기 학습 기록**

방산 임베디드 SW 개발자를 목표로, 교육에서 배운 개념과 실습 과정, 문제 해결 경험을 쌓아가는 TIL(Today I Learned) 저장소입니다.

## 프로젝트 목표

- C/C++와 메모리 동작 원리를 이해하고 하드웨어를 제어하는 코드를 작성한다.
- MCU, RTOS, 임베디드 Linux를 학습하며 소프트웨어와 하드웨어가 연결되는 과정을 설명할 수 있도록 한다.
- 방산 임베디드 SW 진로를 준비하며 실시간성, 안정성, 예외 처리와 검증을 고려하는 개발 습관을 기른다.
- 실습 결과와 오류 해결 근거를 기록해, 직접 구현하고 검증한 경험을 보여주는 포트폴리오로 발전시킨다.

## 방산 임베디드 SW 역량을 위한 실습 목표

교육 실습과 프로젝트에서 아래 항목을 적용하고, 확인한 결과를 기록합니다.

- **실시간성:** 주기 작업의 실행 시간과 지연을 측정하고 목표 주기 충족 여부 확인
- **안정성:** 잘못된 입력, 통신 끊김, 타임아웃 등 실패 조건을 정의하고 처리 결과 확인
- **자원 관리:** 메모리 수명과 공유 자원 접근을 점검하고 누수·경쟁 상태의 원인 분석
- **검증과 추적:** 요구사항별 테스트 조건, 기대 결과, 실제 결과를 연결해 기록

## 기록 방식

각 TIL은 다음 흐름으로 작성합니다.

1. **학습 주제와 목표:** 무엇을 배우고 확인하려 했는지
2. **핵심 개념:** 동작 원리와 이해한 내용을 자신의 말로 정리
3. **실습 환경과 코드:** 사용 장비·도구, 빌드 및 실행 방법
4. **결과와 문제 해결:** 기대 결과, 실제 결과, 오류 원인과 해결 과정
5. **회고와 다음 할 일:** 부족한 부분과 이어서 확인할 내용

프로젝트는 요구사항 → 설계 → 구현 → 테스트 → 회고 흐름으로 정리하고, 외부 자료를 참고한 경우 출처를 함께 남깁니다.
